Демонстрація UI елементів

1. Radiobutton

Дозволяє вибрати лише один варіант із групи.

2. Checkbox

Дозволяє вибрати один або кілька варіантів незалежно один від одного.

3. Text input

Дозволяє ввести короткий текст (ім'я, пошту, запит).

4. Tabs

Розділяє вміст на розділи, показуючи лише активний.

Вміст першої вкладки.
Вміст другої вкладки.
Вміст третьої вкладки.

5. Button

Запускає дію після натискання.

6. Text label

Підписує інший елемент і пояснює його призначення.

7. Link

Переносить користувача на іншу сторінку чи ресурс.

Перейти на Wikipedia

8. Tooltip

Показує додаткову підказку при наведенні курсора.

Наведіть курсор Це випадаюча підказка

9. Dropdown list

Дозволяє вибрати один варіант зі списку, що розкривається.

10. Data grid

Відображає дані у вигляді таблиці з рядків і стовпців.
